`идея → контекст → агент → проверка → рабочий результат`

я собираю продукты с AI и проектирую работу агентов: ставлю задачи, собираю контекст, проверяю результат. если агент уверенно сделал ерунду, красивый отчёт его не спасёт.

в `adhd ai` показываю эту кухню как есть: что дал агенту, где он облажался, что пришлось переделать и какой результат в итоге выжил.
